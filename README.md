# 🌍 APNA ROUTE — SIH 2026

> **"Your Journey, Your Way."**  
> Smart Tourism Platform with Ground Reality Travel Intelligence & Rapid Safety Network.

Built for the **Smart India Hackathon (SIH 2026)** under the **Travel & Tourism** theme.  
Repository: [https://github.com/Adityapatil8032/ApnaRoute.git](https://github.com/Adityapatil8032/ApnaRoute.git)

---

## 🌟 20 Key Features Implemented

1. 🤖 **AI Trip Planner** – Synthesizes ground-realistic itineraries based on destination, duration (2–7 days), budget tier, transit preferences, accommodation style, and interests.
2. 🌦️ **Season-Wise Planning** – 4-season deep dive (Winter, Summer, Monsoon, Autumn) with road accessibility statuses (*Chains Recommended*, *Landslide Caution*, *Pleasant*).
3. 🔍 **Smart Search** – Instant multi-criteria destination, traveler, and interest search with live categorization and sorting.
4. 🗺️ **Hyper-Local Map Radar** – 7-category proximity radar across Stays, Food, Buses, Rickshaws, Bazaars, Hospitals, and Fuel Stations with distance indicators.
5. 📍 **GPS Trip Tracking** – Live transit waypoint telematics, vehicle speed monitoring against hill limits, and real-time transit telemetry.
6. 🛡️ **Route Safety Analysis** – Automated risk indexing (91/100 Safe), road terrain warnings, fog night driving alerts, and trauma unit assignments.
7. 💰 **Dynamic Cost Calculator** – Real ground pricing for hotels, union cabs, authentic meals, and permit fees with interactive per-person budget splitting.
8. 👥 **Connect Travelers** – Match with verified companions based on travel style (*Backpacker*, *Photographer*, *Solo Female*), shared dates, and split union cab fares.
9. 💾 **Save Trips / My Trips** – Personal trip vault for saving itineraries, favoriting destinations, and archiving logged trip milestones.
10. 🚨 **Emergency SOS (112 Radar)** – 1-click GPS location broadcast, nearest police & trauma center coordinates, and direct emergency helplines.
11. ⏰ **Timing Conflict Detection** – Flags schedule clashes between train delays, museum preservation closures, and mountain pass permits with 1-click auto-fix recommendations.
12. 🌤️ **Live Weather & AQI** – Comprehensive temperature, condition, precipitation risk, and real-time Air Quality Index (AQI 42 Good) with health advisories.
13. 🎒 **Smart Packing AI** – Dynamic season & activity checklist engine with interactive completion tracker and essential mountain gear alerts.
14. 🏨 **Travel Services** – Certified local hotels, verified transport operators, vehicle rentals, and adventure guides with SIH verification badges.
15. ⭐ **Reviews + AI Sentiment** – Dual-aspect AI sentiment engine comparing verified positive highlights against on-ground practical issues.
16. 🧑💼 **Verified Local Guides & Bazaars** – Direct booking and fair-trade empowerment for indigenous guides, craft cooperatives, and night markets.
17. 🏛️ **Heritage Intelligence** – Architectural lineage, cultural dress codes, temple etiquette rules, and regional dialect phrases (*"Kasa aahat?"*, *"Namaskara"*).
18. 🤖 **AI Concierge** – Global floating AI travel assistant answering queries on mountain taxi union laws, packing tips, and local delicacies.
19. 🔔 **Smart Notifications** – Proactive alerts drawer for weather changes, road transit delays, and itinerary updates with unread count badge.
20. 📱 **Responsive Futuristic UI** – Premium dark glassmorphism styling, vibrant accents, smooth micro-interactions, and full mobile-first responsiveness.

## 🛠️ Tech Stack & Architecture

- **Core**: React 18, TypeScript, Vite 5
- **Styling**: Tailwind CSS, Glassmorphism, Custom Theme Tokens
- **Icons**: Lucide React
- **Hosting / Deploy**: Vercel ready with configured `vercel.json` and single-page app redirects (`public/_redirects`).
- **Philosophy**: Lightweight, student-friendly, modular components with zero heavy third-party lock-ins.

## 🚀 Quick Start Guide

```bash
# 1. Clone repository
git clone https://github.com/Adityapatil8032/ApnaRoute.git
cd ApnaRoute

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```

The application runs locally on `http://localhost:5173`.
